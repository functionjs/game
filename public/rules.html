Bot Championship

Goal

Create Your smart javascript function to Win in the distributed Nim-like Game .

Rules

  1. There are many accounts: account0, account1, account2, ....
  2. Each account has a random initial number of coins 🪙.
  3. Player - your Bot - play against other Bots in tournament.
  4. On a every turn, a Player:
    • Can only see the current state of the game (number of coins in each account) and the forbidden moves.
    • Cannot see the history of the game or the opponent's Bot code.
    • Selects ANY nonempty account
    • Removes ANY correct (non-forbidden) positive number of coins
  5. Player who removes the last coin wins.

What You Must Implement

You must implement a smart javascript function play() with no more than 4096 bytes of code that will allow your bot to make optimal and quick moves in the game.


Your function play() will be called by the game engine on every turn with the current state of the game and the forbidden moves as input, and it must return the account index and the number of coins to remove as output.
